# Minecraft Server (Crafty + Playit)

## Arrancar
    bash start.sh

## Primeira vez: ligar o Playit à tua conta
    bash playit/claim.sh
Abre o link, entra na tua conta playit.gg e aprova. Depois cria um túnel Minecraft Java (TCP) para a porta local do teu servidor (25500-25600).

## Crafty
Aba Ports do Codespace, porta 8443. Credenciais iniciais em `crafty/data/config/default-creds.txt`.
